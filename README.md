# Pyceleritas
### A cozy 2D car game made with Python as a school project.

Pyceleritas is a cozy 2D car game developed with Python and the Pygame library.

## About

The goal of this project is to create a cozy 2D car game where you can drive around in a small open-world map and simply have some fun!

The car will be controlled using the W, A, S, and D keys, the Q and E keys, and the spacebar.

The game will include features such as:

- An open world
- A camera that follows the car
- Collision detection
- Sound effects
- Animations
- Three different radio stations

More features may be added during development.

## Goal

The main goal is to develop a 2D open-world video game and achieve a polished result by the end of the development process.

I want to learn how to implement and handle things such as:

- Camera systems
- Collision detection
- Driving physics
- Animations
- Sound design

## Status

🚧 **In development**

The game is still in an early stage of development. More features and improvements will be added over time.
